# Dropbox Clone

A pixel-perfect static clone of the Dropbox landing page built with pure HTML, CSS, and JavaScript — no frameworks, no libraries, just clean handwritten code.

🔗 **Live Demo:** [r1-dropbo-clone.netlify.app](https://r1-dropbo-clone.netlify.app)


---

## 🚀 Features

- Responsive layout that works across desktop and mobile
- Pure CSS styling with no frameworks or libraries
- Clean semantic HTML structure
- Smooth UI replicating the Dropbox interface

---

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantics |
| CSS3 | Styling, layout, and responsiveness |
| JavaScript | UI interactions |

---

## 📁 Project Structure

```
Static-Dropbox/
├── Style/          # CSS stylesheets
├── images/         # Images and assets
└── index.html      # Main HTML file
```

---

## 🏃 Run Locally

No installation needed — just clone and open in your browser.

```bash
# Clone the repository
git clone https://github.com/rinshamol/Static-Dropbox.git

# Navigate into the project
cd Static-Dropbox

# Open in browser
open index.html
```

Or simply double-click `index.html` to open it in your browser.
